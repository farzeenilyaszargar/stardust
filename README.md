# StarWander ⭐

StarWander is an ambitious chess bot project with a bold goal: become stronger than Stockfish, Reckless, Leela Chess Zero, and other leading chess engines.

The project is just getting started. Beating these engines is a long-term ambition, and StarWander has no measured playing strength yet.

## Development plan

- Build a reliable chess engine with legal move generation and complete chess rules.
- Add position evaluation and a search algorithm to find strong moves.
- Support the Universal Chess Interface (UCI) to work with chess GUIs and engine testing tools.
- Improve search, evaluation, and time management through testing.
- Benchmark against established engines under consistent hardware and time controls, and publish results.

## Getting started

```sh
git clone https://github.com/farzeenilyaszargar/starwander-chess.git
cd starwander-chess
```

Engine code, build instructions, and playing instructions will be added as development progresses.
